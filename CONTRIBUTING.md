# Afspraken over samenwerking

## Communicatie
Communicatie gaat via Teams of op locatie.

## Oplevering
Ieder teamlid maakt gebruik van feature branches en voegt goedgekeurde code toe via Pull Requests.

## Afwezigheid
Afwezigheid voor 10:00 melden via Teams.

## Verantwoordelijkheid
Ieder teamlid is verantwoordelijk voor zijn/haar's vroegtijdelijke oplevering, dit reflecteerd respect voor elkaar hebben.
